# iSKA-Gen Benchmark v1.1.0 변경 로그

**발행일:** 2025년 8월 8일  
**버전:** v1.1.0  
**이전 버전:** v1.0.0

## 📋 주요 변경사항 개요

### 1. 벤치마크 ID별 평가 유형 특화
- **ID 1-2**: 읽고 말하기 유형 대응
- **ID 3-4**: 듣고 말하기 유형 대응  
- **ID 5**: 보고 말하기 유형 대응

### 2. 벤치마크 구조 변경
- **ID 2**: 비교형에서 단일 주제형으로 변경 (`korean_topic/foreign_topic` → `topic/context`)
- **ID 5**: 새로운 보고 말하기 유형 추가 (기존에는 없었음)

---

## 🔍 상세 변경 내용

### ID 1: 제목을 붙인 근거 설명하기 + 자문화와 비교하기 + 원인과 전망 예측하기
**변경사항:** 구조 유지, 내용 보강
- 기존 v1.0.0 구조 유지 (korean_topic/foreign_topic 비교형)
- 평가 목표 및 문제 유형 미세 조정
- 아이템 수: 50개 유지

### ID 2: 문제 상황 요약하기 + 문제 해결 방안 제안하기 + 기대 효과 및 부작용 설명하기  
**⚠️ 주요 변경사항:** 구조 완전 개편
- **기존:** 비교형 구조 (`korean_topic` vs `foreign_topic`)
- **신규:** 단일 주제형 구조 (`topic` + `context`)
- **목적:** 읽고 말하기 유형에 특화된 국내 문제 해결 중심 평가
- **아이템 예시:**
  - 중장년층의 재취업 문제
  - 층간소음 문제  
  - 일회용 컵 남용 문제
  - 유기동물 문제 등

### ID 3: 찬성/반대 입장 논거 파악하기 + 논리적 근거 제시하기 + 예상 반론에 재반박하기
**변경사항:** 구조 변경
- **기존:** 비교형 구조 (`korean_topic` vs `foreign_topic`)  
- **신규:** 단일 주제형 구조 (`topic` + `context`)
- **목적:** 듣고 말하기 유형에 특화된 찬반 논쟁 중심 평가
- **아이템 예시:**
  - 사형제 존폐 논란
  - 공공장소 CCTV 확대 설치
  - 인터넷 댓글 실명제 도입
  - 화장품 동물실험 금지 등

### ID 4: 두 대안의 핵심 차이점 파악하기 + 주어진 기준에 따라 장단점 분석하기 + 최종 선택 및 결정 이유 정당화하기
**변경사항:** 구조 변경
- **기존:** 비교형 구조 (`korean_topic` vs `foreign_topic`)
- **신규:** 단일 주제형 구조 (`topic` + `context`)  
- **목적:** 듣고 말하기 유형에 특화된 선택 및 의사결정 중심 평가
- **아이템 예시:**
  - 신문 구독 vs 뉴스 앱 이용
  - 아파트 vs 단독주택 거주
  - 패키지여행 vs 자유여행
  - 대기업 취업 vs 스타트업 취업 등

### ID 5: 일상 문제 해결 경험 말하기 (신규)
**⚠️ 완전 신규 추가**
- **목적:** 보고 말하기 유형 대응
- **구조:** 단일 주제형 (`topic`)
- **현재 상태:** 개발 중 (1개 아이템만 존재)
- **아이템:** 쓰레기 분리배출
- **특징:** `problem_types`와 `eval_goals`가 부분적으로만 정의됨

## 🎯 평가 유형별 특징

### 읽고 말하기 (ID 1-2)
- 주어진 텍스트 정보를 바탕으로 한 이해 및 분석 능력 평가
- ID 1: 문화 비교 분석
- ID 2: 문제 해결 방안 제시

### 듣고 말하기 (ID 3-4)  
- 음성으로 제시된 정보를 바탕으로 한 논리적 사고 및 의사결정 능력 평가
- ID 3: 찬반 논쟁 및 논리적 근거 제시
- ID 4: 대안 비교 및 선택 정당화

### 보고 말하기 (ID 5)
- 시각적 자료를 바탕으로 한 설명 및 경험 공유 능력 평가
- ID 5: 일상 경험 기반 문제 해결 설명

## 🔄 v1.0.0 대비 호환성

### 호환 가능
- **ID 1**: 기존 v1.0.0 구조와 완전 호환

### 호환 불가
- **ID 2, 3, 4**: 구조 변경으로 인한 호환성 없음
- **ID 5**: 신규 추가로 v1.0.0에 없음

### 마이그레이션 가이드
v1.0.0에서 v1.1.0으로 전환 시:
1. ID 1은 그대로 사용 가능
2. ID 2, 3, 4는 새로운 프롬프트 템플릿 필요:
   - `create_domestic_passage`
   - `create_dialogue_passage`  
   - `violate_*_severely_domestic`
3. ID 5는 완전 신규 개발 필요
